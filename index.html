How to use UPA

Best use

Describe the role, task, input data, constraints, examples, and desired output. UPA produces a complete markdown prompt file that can be pasted into Claude, Gemini, or a prompt library.

Modification work

Paste the existing prompt in the context box and choose Modify. UPA will add a surgical modification protocol so the generated assistant preserves unrelated formatting and logic.

Privacy

This static app runs in the browser. Saved snapshots use localStorage on your device. No server, account, database, or analytics are required.
